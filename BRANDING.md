# Nesk Drive branding

## Product identity

The product name is **Nesk Drive**. Use that name in release notes, installer
copy, user-facing documentation, and support material.

- Application ID: `ch.nesk.drive`
- Required service for Nesk releases: `https://files.nesk.ch`
- Supported pilot operating systems: Windows 10 x64 and Windows 11 x64

Nesk Drive is a branded, GPL-2.0-or-later fork of the ownCloud Desktop Client.
Upstream ownCloud names, copyright notices, and license notices retained in
the source must not be removed or misrepresented. This fork tracks the
ownCloud `v7.1.0` base on `nesk/stable-7.1`; upstream changes are incorporated
only after Nesk review.

## Release naming

Use the `Nesk Drive` product name for Nesk-built installers and release assets.
Do not imply that a Nesk release is an official ownCloud release. Releases must
link to their corresponding source in this repository and retain the GPL
notices required by [COPYING](COPYING).
